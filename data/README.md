# Introduction
Data used in the manuscript: Who is holding the reins? Evaluating diagnostic drivers and veterinary opinions on Streptococcus equi testing in horses

## File description
All data are presented in 'whosholdingthereins - datasets.xlsx' under separate sheets as described below:

### Geographical coverage
Respondents information (annonymised), for plotting and summarising geographical location of respondents. 
*note only half postcode has been provided for privacy reasons. The original dataset has full postcode for best resolution
### sample date
Date that the respondent took the sample they were answering the survey for
### LIMS - additional info
Sheet used to verify the A/C results respondents provided in their survey answer, or to link up to lab ID provided were vets didn't give an A/C results
###  premises info
Answers from respondents pertaining to the type of premises the sampled horse resided on
### reason for testing and outcome
Answers as to the reason for testing for the sampling event vets were answering the survey for, the test results and the vets interpretation and actions based on the result
### Opinions on testing
Likert scale answers to the scenarios provided for using strangles serology alongside open text answers which were use for thematic analysis. 

####Shared fields:
- EIDSID: anonymised ID given to respondents answers for tracking across all analyses
- vetpracticeID: anonymised ID given to the vet practice that the respondent was based at
- LabID_Coded: anonymised ID of the lab sample ID for repository purposes. The original Lab Id was used for LIMS management and result tracking in the original analyses
